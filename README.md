# Twitter's Birdwatch: a case study of crowd-sourced fact-checking

Data and conference materials from a case study of Birdwatch, Twitter's crowd-sourced fact-checking program (renamed Community Notes in late 2022). The study examined the program's output by comparing tweets flagged as misleading by Birdwatch contributors with those that were not, and asked what the program's early record implied for community-based correction of misinformation.

**Author:** Merriah A. Croston, Washington University in St. Louis.

## Outputs

- Croston M. (2022, November). *Twitter's Birdwatch: A case study of crowd-sourced and community-based fact-checking.* 20th Annual Community Informatics Research Network (CIRN) Conference, Prato, Italy. [Slides](croston_cirn_2022_FINAL.pdf)

## Data

Both files are a snapshot of Birdwatch's public data download, taken in August 2022. Column definitions follow Twitter's Birdwatch data guide of that period.

| File | Contents |
| --- | --- |
| `notes-00000.tsv` | 35,832 contributor notes written through August 8, 2022: note ID, anonymized participant ID, the tweet the note addresses, the contributor's classification and reasons, and the note text. |
| `noteStatusHistory-00000.tsv` | Status history for 36,118 notes (for example, Needs More Ratings, Currently Rated Helpful, Currently Rated Not Helpful), with timestamps. |

Tweet content is not shared, in line with X's developer terms. Current Community Notes data are available from X.
